# CivicEye

AI-powered civic issue reporting and tracking platform.

## Problem Statement

Citizens often struggle to report civic issues such as potholes, garbage accumulation, and damaged infrastructure. Tracking complaint resolution is often difficult and lacks transparency.

## Solution

CivicEye enables citizens to report civic issues with images, while authorities can monitor, prioritize, and resolve complaints through a centralized dashboard.

## Features

- AI-based issue detection
- Pothole and garbage identification
- Severity classification
- Citizen complaint portal
- Authority dashboard
- Progress tracking
- Complaint resolution workflow
- Firebase cloud database
- Clickable complaint images
